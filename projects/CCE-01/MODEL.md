# CCE-01 Model Specification

## 1. Purpose

CCE-01 explores a temporal model in which computation is considered as the evolution of distinguishable states and relationships.

## 2. Temporal anchors

### T₀ — Computational Origin

A chosen model boundary representing the assumed beginning of distinguishable state. The prototype currently provides selectable demonstration baselines, including a 13.800 billion-year cosmic-scale baseline.

### T₁ — First Computation

A chosen model boundary representing the assumed point at which distinguishable states participate in an evolving computational process. T₁ is presently configurable as an offset from T₀.

**T₀ and T₁ are model assumptions, not established scientific observations.**

## 3. State progression

The visualization uses eight conceptual phases:

1. Differentiation
2. State
3. Structure
4. Complexity
5. Life
6. Mind
7. Machine
8. Now

These labels are conceptual research categories, not claims of sharply defined scientific transition points.

## 4. Temporal scale

The prototype maps modeled elapsed time into years, seconds and normalized position. The displayed state-transition figure is illustrative: it currently uses elapsed seconds as a proxy and must not be interpreted as a measured count of physical computational events.

## 5. Local Array extension

Future versions should represent nested cycles and observations including Earth rotation, Earth orbital position, lunar phase, seasons, solar rotation/activity and solar weather. Calculated ephemerides and live observations should be clearly distinguished from model assumptions.

## 6. Integrity principle

CCE-01 should preserve a visible boundary between:

**ASSUMPTION → MODEL → CALCULATION → OBSERVATION → INTERPRETATION**

No visualization should silently convert a model assumption into an observed fact.
