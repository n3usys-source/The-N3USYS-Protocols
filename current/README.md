# Current N3USYS Framework

This directory is the authoritative home for the present-generation N3USYS framework.

The repository contains substantial early-generation material. Those artifacts remain valuable, but they are historical unless explicitly promoted into this directory.

## Authority

Material under `/current/` defines the current framework as it is formally established.

### Normative material

- `specification/` — definitions, principles, architecture, ontology, and terminology.
- `protocols/` — operational protocols and required behaviors.
- `architecture/` — system-level structure and component relationships.
- `terminology/` — controlled vocabulary and versioned meanings.

## Development rule

Historical experiments may inform or challenge the current framework, but they do not silently redefine it. Changes to current doctrine should be explicit, versioned, and attributable to the evidence or design decision that caused the change.

## Generation boundary

If an artifact predates the current N3USYS architecture and its status is uncertain, preserve it as historical until its relationship to the current framework is established.
