# CCE-01 Development Roadmap

## v0.1 — Cosmic prototype

- Self-contained browser implementation
- Living temporal visualization
- T₀/T₁ model controls
- Timeline scrubbing and playback
- Differentiation → State → Structure → Complexity → Life → Mind → Machine → Now
- Explicit scientific-status disclaimer

## v0.2 — Local Array

Add nested astronomical and terrestrial cycles:

- Earth axial rotation
- Earth solar orbit
- Solar rotation
- Solar activity
- Solar weather
- Moon phase and synodic cycle
- Solstices
- Equinoxes
- Seasons
- Day/night
- Current Now marker

## v0.3 — Data integrity layer

Separate every displayed value into one of four states:

- **MODEL** — selected assumption
- **CALCULATED** — derived locally from known inputs
- **OBSERVED** — supplied by an external observational data source
- **INTERPRETED** — conceptual N3USYS framing

## v0.4 — Multi-scale navigation

Allow continuous zoom from cosmic time to astronomical cycles to terrestrial time and finally to the current second.

## v0.5 — Documentation and reproducibility

Add machine-readable model parameters, data-source records, calculation notes and versioned experiment logs.

## Design principle

The instrument should make temporal scale visible without implying that conceptual boundaries are established scientific facts.
