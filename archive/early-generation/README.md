# Early-Generation N3USYS Archive

This namespace preserves the historical development record of the N3USYS Protocols.

The material here may include superseded terminology, architectural assumptions, experiments, prototypes, and documentation. Its historical value is intentional.

## Rule

Do not rewrite an old artifact solely to make it agree with the current framework. If later work supersedes it, establish that relationship explicitly in current documentation or the migration manifest.

## Status

The repository's existing top-level directories are being migrated into this archive and into the new research/implementation/publication namespaces in stages. Until a specific artifact is migrated, its original location remains authoritative for historical retrieval.
